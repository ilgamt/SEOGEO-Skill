# SEO / GEO Audit Skill

Универсальный скилл для Codex: технический SEO-аудит, анализ поисковой видимости Google и Яндекса, диагностика индексации и проверяемые возможности GEO-продвижения.

Основной файл: [seo-audit/SKILL.md](seo-audit/SKILL.md).

## Состав

- [Полная карта аудита](seo-audit/references/audit-map.md): источники, проверки, доказательства, приоритеты и формат результата.
- [Технические проверки](seo-audit/references/technical.md): доступность, обход, индексация, рендеринг, метаданные и UX.
- [Поисковые данные и GEO](seo-audit/references/search-and-geo.md): Google Search Console, Яндекс Вебмастер, аналитика, Алиса AI и другие AI-платформы.
- [Диагностика роста и качество отчета](seo-audit/references/growth-and-quality.md): изменения после релизов, падение эффективности контента, конкуренция страниц, шаблонные посадочные, AI-источники и критерии задач.
- [Метаданные Codex](seo-audit/agents/openai.yaml).

## Результат аудита

Отчет содержит конкретные находки с доказательствами, полные URL, подробные действия и финальный план задач для передачи исполнителю. Аналитические данные по умолчанию рассматриваются за последние шесть месяцев с помесячной детализацией, если источник позволяет получить такую историю.

Проверки адаптируются к типу сайта, рынку и доступным данным. Ограничения доступа и выборки указываются явно. Скилл не гарантирует индексацию, позиции, трафик или AI-цитирования; подключение платных сервисов и изменение сайта не выполняются автоматически.

Методические источники перечислены в [справочнике диагностики](seo-audit/references/growth-and-quality.md#источники-идей). Клиентские отчеты, данные кабинетов и учетные данные в состав репозитория не входят.
